How it is built

Each section keeps its existing CSF fields exactly as they are, then gets one extra field appended last:

array( 'id' => 'de_viewer_pro_info', 'type' => 'content', 'class' => 'bplde-pro-field', 'content' => '…html…' )

That is the only thing added. No field id changes, so nothing saved on an existing document is orphaned. No fake inputs anywhere — the block is static markup with no name attributes, so it can never post a value or collide with a Pro field later. vendor/Codestar/ is not touched.
